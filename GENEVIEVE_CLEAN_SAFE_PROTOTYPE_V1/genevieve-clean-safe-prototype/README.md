# GENEVIEVE CLEAN-SAFE™ Prototype

This Vite + React prototype includes:

- GenevieveSaniStation™ with:
  - hands-free deposit simulation
  - Prepare for Collection workflow
  - public opening lockout
  - odour extraction
  - double-seal sequence
  - cut-between-seals sequence
  - seal verification
  - automatic service-door lockout on failed seal
  - backup seal retry
  - sealed cassette removal
  - fill, weight, odour, leachate and seal-quality telemetry

- GenevieveBagStation™ with:
  - one-bag-at-a-time dispensing
  - bag pre-opening
  - withdrawal confirmation
  - sealed waste chute
  - bin, stock and odour monitoring
  - remote lock
  - cassette service reset

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

This is a visual and logic prototype only. It does not control real motors, heaters, blades, locks, sensors or sanitation equipment. Physical deployment requires professional mechanical, electrical, safety, infection-control and regulatory engineering.
